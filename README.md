# ReMade — Giving the past a future.

Customer-validation MVP for ReMade, a B2B circular-economy marketplace in Lisbon for reclaimed construction wood. It connects construction and renovation companies that have reusable wood with the architects and interior designers who want material with character and provenance. Every material carries a **Material Passport**.

The site exists to test four things:

1. Will builders offer reusable wood instead of disposing of it? → **“I have wood to offer”** (`/offer`)
2. Do architects and designers want reclaimed wood? → **“I’m looking for wood”** (`/designers`)
3. Do they value provenance enough to pay a premium? → the premium and “what matters most” questions on `/designers`
4. What types of wood are they looking for? → wood type on `/designers` and per-material requests on each passport

## Pages

| Route | What it does |
| --- | --- |
| `/` | Hero, problem, how it works, featured materials, Material Passport showcase, final CTA |
| `/materials` | Curated catalogue (7 listings) with type, location, condition and availability filters |
| `/materials/[id]` | Material Passport: gallery, passport record, story, sources, environmental impact, request form |
| `/offer` | For builders: proposition plus the short “Report my material” form (with photo upload) |
| `/designers` | For architects and designers: available materials plus the “Join ReMade” form |
| `/about` | Mission, why Lisbon, wood and B2B, and the team |
| `/admin?key=…` | Internal validation metrics, survey tallies, submissions and CSV export |

## Content rules for the catalogue

All listings live in `src/lib/materials.ts`. Each one references a **real** Lisbon-area building or project: Pombaline Baixa, Alfama and Mouraria, Hub Criativo do Beato, Hospital Miguel Bombarda, Quartel da Graça, Cidade da Água (former Lisnave, Almada) and the former CUF complex in Barreiro. The building facts are sourced, and the sources are linked on each passport. ReMade has **not** recovered material from any of these sites, so every listing is labelled **“Prototype material — potential recovery source”**. Species, age and previous use are marked “To be verified” unless known. Quantities, dimensions and CO₂ figures are indicative placeholders.

When a real material is verified, replace its entry: set the real facts, drop the “To be verified” values and swap in real photographs.

## Images

The images in `public/images/materials/` are **procedural renders**, not photographs. They are generated by `scripts/render_wood.py` (numpy/scipy/Pillow) and captioned as illustrative on the site. Replace them with real photography as materials are documented. Keep the same file names, or update the `images` array for the listing.

## Data and measurement

- **Storage:** form submissions and analytics events are stored in SQLite (`node:sqlite`, built into Node ≥ 22.5) at `data/remade.db`. Uploaded photos go in `data/uploads/`. Change the location with `REMADE_DATA_DIR`. The `data/` folder is git-ignored.
- **Analytics:** anonymous and cookie-free. A random visitor id is kept in localStorage. The site records page views, Material Passport views, clicks on every CTA (`data-cta`) and filter use. Bots and headless browsers are ignored.
- **Metrics** (`/admin`): visitors, builder submissions, designer sign-ups, material requests, visitor → sign-up conversion, passport view → request conversion, premium willingness, what matters most, wood types wanted, and per-material views and requests. Each submission table can be downloaded as CSV.

### Environment variables

| Variable | Purpose |
| --- | --- |
| `ADMIN_KEY` | Required in production to open `/admin?key=…` and the CSV export. In development, admin is open when unset. |
| `REMADE_DATA_DIR` | Where the SQLite database and uploads live (default `./data`). |
| `FORMS_WEBHOOK_URL` | Optional. Every submission is also POSTed as JSON to this URL (Google Apps Script, Zapier, Make, Slack…). Use it on hosts without a persistent disk, such as serverless platforms. |

Deploy on a host with a persistent disk (a VPS, Render, Railway or Fly.io with a volume) to use the built-in database. On serverless hosts, set `FORMS_WEBHOOK_URL` so no submission is lost.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · `node:sqlite`. There are no accounts, checkout, payments or messaging, by design.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && ADMIN_KEY=secret npm start
```

`legacy-prototype/` holds the previous furniture-marketplace prototype, kept for reference only. It is excluded from the build, type-checking and linting, and can be deleted.
